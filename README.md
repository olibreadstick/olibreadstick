### 🤖 Agentic Mobility Assistant – Context-Aware Daily Mobility Planning

🔗 Repository: https://github.com/olibreadstick/agentic-mobility-assistant
🌐 Live Demo: https://agentic-vehicle-assistant.vercel.app/

Developed a **context-aware agentic AI system** that coordinates daily household mobility using a shared electric vehicle.

The system combines **bounded LLM agents with deterministic mobility-processing components** to transform multiple household calendars, vehicle conditions, and environmental information into a continuous daily mobility mission.

Key features include:

* Multi-calendar household mobility planning
* Constraint-aware caregiver and dependent coordination
* Traffic-aware route generation and geocoding
* Construction-aware route adaptation
* Electric-vehicle charging coordination
* Passenger continuity and shared-vehicle scheduling
* Persistent route memory for follow-up interactions
* Conversational calendar modification
* React-based user interface connected to an n8n agentic workflow

The system was evaluated across multiple GPT and Gemini models and compared with reduced generalist-agent architectures. The proposed architecture achieved **94.44% mean route accuracy** in the Montréal household case study.

**Technologies:** React, JavaScript, n8n, LLMs, OpenAI, Google Calendar, TomTom APIs, REST APIs, JSON
